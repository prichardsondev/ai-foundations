Part 2 - Section 4

How a Neural Network Learns

A neural network learns by making a prediction, measuring how wrong it was, and making small adjustments. In this lesson, you will see every part of that loop and train a tiny network to solve XOR.

By the end of this lesson, you should be able to

  • Explain inputs, weights, biases, activation functions, outputs, targets, and loss.
  • Describe an epoch and a learning rate in plain language.
  • Explain how backpropagation and gradient descent help a network learn.
  • Tell the difference between training and inference.
  • Train, save, inspect, and use a small neural network from GitHub.

1. The whole idea in one loop

A model does not begin with the answer. It begins with adjustable numbers and improves them through examples.

example inputs
  -> make a prediction
  -> compare prediction with the target answer
  -> measure the error (loss)
  -> work backward to find useful adjustments
  -> update weights and biases
  -> repeat with more examples

Training means changing parameters

The adjustable numbers inside this network are its weights and biases. Training changes them. When the trained model later makes a prediction without changing them, that is inference.

2. Our learning problem: XOR

XOR means “one or the other, but not both.” Its four examples are the network's complete training dataset.

Input AInput BTarget answerMeaning
000The inputs are the same.
011The inputs are different.
101The inputs are different.
110The inputs are the same.

Why use such a small problem?

Real AI models may contain billions of parameters and learn from enormous datasets. XOR is small enough that we can inspect the entire dataset, count every parameter, and watch learning happen in seconds.

3. The network's shape

Information moves from the inputs, through a hidden layer, to an output.

2 input values  ->  2 hidden neurons  ->  1 output value

        4 input-to-hidden weights
      + 2 hidden-to-output weights
      + 2 hidden biases
      + 1 output bias
      = 9 learned parameters

Layers

The input layer receives the two values. The hidden layer combines them into intermediate signals. The output layer produces one number between 0 and 1.

Parameters

The architecture describes how neurons are connected. The parameters are the weights and biases that training adjusts. This project has only nine, so the saved model is easy to inspect.

4. Every part, in plain language

These terms describe different jobs inside one learning process.

PartSimple explanationIn the XOR lab
InputThe information given to the model.Two values such as [0, 1].
WeightControls how strongly one value influences the next neuron. Positive and negative weights can push a result in different directions.Six connection strengths.
BiasAn adjustable offset. It lets a neuron shift when it becomes active instead of always being anchored at zero.Two hidden offsets and one output offset.
Activation functionTransforms a neuron's combined value and adds nonlinearity, allowing the network to learn more than a straight-line rule.The sigmoid function returns values between 0 and 1.
PredictionThe answer calculated with the current parameters.A number such as 0.9825.
TargetThe correct answer in a training example.Either 0 or 1.
LossA number measuring how far predictions are from their targets. Lower is better.Mean squared error across the four examples.

Weights and biases are learned; settings are chosen

The network learns its weights and biases from examples. A person chooses settings such as the number of epochs, the learning rate, and the network architecture. Those choices are often called hyperparameters.

5. What an activation function does

A neuron first calculates a weighted sum plus a bias. An activation function then transforms that value.

neuron output = activation((inputs x weights) + bias)

Sigmoid

Squashes any number into the range 0 to 1. That makes it convenient for this lab's yes-or-no output. Very large values can make sigmoid neurons saturate and learn slowly.

ReLU

Returns zero for negative values and the original value for positive values. It is common in hidden layers of larger networks, but it is not used in this tiny project.

Softmax

Turns several output scores into values that add to 1. It is often used when a model must choose among several categories.

Why nonlinearity matters

Without nonlinear activation functions, stacking more layers would still behave like one linear calculation. XOR cannot be separated by one straight line, which is why it is a classic teaching example.

6. Epochs and learning rate

These settings control how long the model practices and how large each adjustment is.

Epoch

One epoch is one complete pass through the training dataset. This dataset has four examples, so one epoch shows the network all four. The program updates parameters after each example.

Too few epochs may leave the model undertrained. More epochs mean more opportunities to learn, but more is not automatically better for every model.

Learning rate

The learning rate controls the size of each parameter adjustment. A very small rate may learn slowly. A useful rate makes steady progress. A very large rate may jump past good values, behave unpredictably, or get stuck.

Change one setting at a time when comparing experiments.

SettingThink of it asPossible result
10 epochsA little practiceUsually not enough to solve XOR.
10,000 epochsRepeated practiceThe default setup reliably learns XOR.
Learning rate 0.01Tiny stepsProgress may be slow.
Learning rate 0.5Useful steps for this projectLoss falls and predictions improve.
Learning rate 100Huge jumpsNeurons may saturate or get stuck.

7. How the error becomes an adjustment

Two related ideas move the network from “wrong” toward “less wrong.”

Backpropagation

Backpropagation works backward from the output error. Using the chain rule from calculus, it calculates how much each weight and bias contributed to the error.

You do not need to calculate the derivatives by hand today. Focus on its job: assign responsibility for the error.

Gradient descent

The calculated gradients point toward increasing loss. Gradient descent takes a small step in the opposite direction to try to reduce loss.

The learning rate controls the size of that step.

forward pass:       inputs -> prediction -> loss
backpropagation:    loss -> responsibility for each parameter
gradient descent:  responsibility -> small parameter updates

8. Training, inference, and RAG are different

RAGRelevant source material is retrieved and supplied as context to an existing model.No

9. In-class lab: watch the network learn

Work through these checkpoints in order. The repository README contains the full explanations, expected output, troubleshooting, and optional agent guide.

No account, API key, or package installation

The lab uses plain JavaScript and Node.js 18 or newer. It has no external code dependencies and makes no cloud API calls.

Checkpoint 1: download and test

mkdir -p ~/projects
cd ~/projects
git clone https://github.com/prichardsondev/xor-neural-network-lab.git
cd xor-neural-network-lab
node --version
npm test

Stop and check: Node should be version 18 or newer and all six tests should pass. If the folder already exists, enter it instead of cloning it again.

Checkpoint 2: observe an untrained model

node train.js --epochs 0 --no-save

Before running it: predict whether the “Before training” and “After training” values will differ.

Stop and check: with zero epochs, no parameter updates occur. Both sections should match and the model should not be saved.

Checkpoint 3: train and save

node train.js

Stop and check: watch mean squared error fall from about 0.265 to about 0.00034. After 10,000 epochs, all four predicted classes should match their targets. The model is saved to model/model.json.

Checkpoint 4: inspect what was learned

python3 -m json.tool model/model.json | less

Press q to exit. Find the architecture, six weights, and three biases. The model file contains learned parameters; it does not contain the four training examples.

Checkpoint 5: run inference

node predict.js

Stop and check: the saved parameters produce the four predictions again. No targets, loss calculation, backpropagation, or training updates are used.

Checkpoint 6: compare epochs

node train.js --epochs 10 --no-save
node train.js --epochs 100 --no-save
node train.js --epochs 1000 --no-save
node train.js --epochs 10000 --no-save

Keep the default seed and learning rate unchanged. For each run, record the final loss, correct classifications, and confidence of the predictions.

Checkpoint 7: compare learning rates

node train.js --learning-rate 0.01 --no-save
node train.js --learning-rate 0.5 --no-save
node train.js --learning-rate 100 --no-save

Keep the epoch count and seed unchanged. Decide which rate is too slow, which learns reliably, and what happens when the update size is extremely large.

Optional: have an agent guide you

Open the cloned repository with Codex or another coding agent. At the end of README.md, copy the Agent-first setup prompt. The agent will present one step at a time and wait for you to observe each result.

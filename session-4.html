Part 1 - Section 4

GPT Chat Models vs AI Agents

Give ChatGPT or Codex one prompt and make a live basement monitoring website. You do not need programming experience.

By the end, you should be able to

  • Explain the difference between a chat model and an AI agent.
  • Explain that an API lets one program request information from another.
  • Tell a current reading, a fixed rule, and a prediction apart.
  • Use an AI assistant to build and test a small website.

What are we doing today?

Follow one path from live data to a working app.

  1. Open the BaseTemp API page.
  2. Try its three live-data links.
  3. Copy the student prompt.
  4. Paste the prompt into ChatGPT or Codex.
  5. Let the AI create the website.
  6. Open the website and test its Refresh button.

If you wonder “What do I do next?”

Return to this numbered list. Complete only the next unfinished step.

1. Chat model vs AI agent

Both use AI, but they help in different ways.

GPT chat model

You ask for something. It responds in the conversation, and you decide what to do next.

Today: Chat can create the website for you.

AI agent

You give it a goal. It can work through several steps and use tools, while asking before important actions.

Today: an agent may inspect the API, create the website, and test it.

An easy way to remember

Chat responds. An agent works toward a goal. The same AI product may do either, depending on the task and the tools it can use.

Two building blocks used today

  • API: a way for one program to request information from another program.
  • Automation: a fixed process that follows rules written in advance.

Your website will request data from an API. The API’s humidity status comes from a fixed rule.

2. Meet the BaseTemp system

The example is real, but the task is small enough to understand.

What is in the basement?

One Raspberry Pi sensor is near the pellet stove. A second sensor is on the far side of the basement. Both report temperature and humidity.

The Pi running the public API also reports its current CPU temperature.

What can the API tell us?

  • Current readings from both basement sensors
  • A summer humidity result based on a fixed rule
  • The current Raspberry Pi CPU temperature

Do not confuse these levels

LevelQuestion answered
Raw readingWhat is happening now?
Coded ruleDid a known threshold get crossed?
TrendHow has the reading changed over time?
PredictionWhat is likely to happen next?

Monitoring is not prediction

One current CPU-temperature reading tells us what is happening now. Predicting a failure would require readings collected over time and examples of what happened afterward.

3. Build your dashboard

Complete one step at a time. You do not need to write or understand the code.

Your job is to direct and check

The AI will do the programming. You will give it clear instructions, follow its save directions, and check that the result works.

Step 1: Open the API page

The BaseTemp page contains the endpoint documentation, live links, and the student build prompt.

Open BaseTemp API

Stop and check: you should see the heading BaseTemp API.

Step 2: Inspect the data

On the BaseTemp page, open /api/all, /api/humidity-status, and /api/pi. Each opens in a new browser tab. Close that tab to return to BaseTemp.

The plain text you see is called JSON. You do not need to understand every line.

Stop and check: each link opens and shows information instead of an error.

Step 3: Copy the student prompt

Find Ask ChatGPT or Codex to build an app on the BaseTemp page. Use its Copy button to copy the entire prompt.

Stop and check: the page confirms that the prompt was copied.

Step 4: Give the prompt to your AI assistant

Open a new ChatGPT or Codex conversation. Paste the prompt and send it.

If it asks permission to inspect the public API, allow it.

Stop and check: the assistant begins creating a basement monitoring website.

Step 5: Let the AI create the website

Wait while the assistant works. Follow the save directions it gives you.

If it creates a file or preview for you, open that. If it gives you website text to save, follow its directions exactly. Ask the instructor for help before changing any code yourself.

Stop and check: you have a file or preview named basement-monitor.html.

Step 6: Open and test the dashboard

  1. Open the file or preview.
  2. Wait for the loading message to disappear.
  3. Press Refresh.

Stop and check: you should see two sensor readings, the summer humidity status, the Pi CPU temperature, and observation times.

Now notice what the AI did

Giving you an answer was chat-like. Opening the API, creating a file, or testing the result used tools and was more agent-like.

Publishing is optional

If the assistant offers to make your website public, it must ask first. Say yes only if you want anyone on the internet to be able to open it.

4. If something does not work

Fix the current step; do not start over.

What you seeWhat to do next
The BaseTemp page will not open.Check your internet connection, reload once, and show the instructor the message on your screen.
The AI cannot inspect the API.Ask it to try its browser. If it still fails, show the instructor.
The website stays on “Loading.”Tell the AI exactly what you see and ask it to fix the website.
You are not sure what to do.Return to the last completed step and read only the next step.

5. Finished checklist

You are done when every item is true.

  • Your dashboard opens.
  • It shows both basement sensors, humidity status, and Pi CPU temperature.
  • The Refresh button works.
  • You know the readings came from the BaseTemp API.
  • You can explain the difference between chat and an agent.

Key takeaway

Chat responds. An agent works toward a goal. In both cases, you check the result and decide whether anything should be made public.

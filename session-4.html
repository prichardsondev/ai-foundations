Part 1 - Section 4

APIs, Automation, and Your First AI-Built App

Today you will use a real public API from two Raspberry Pis, ask ChatGPT or Codex to build a dashboard, save one HTML file, and open your working app in a browser.

By the end, you should be able to

  • Explain an API in one sentence.
  • Tell raw data, coded automation, and prediction apart.
  • Use an AI assistant to build a small app from documented API data.
  • Open the app, refresh its data, and check whether it works.

What are we doing today?

Follow one path from live data to a working app.

1. Open the BaseTemp API page
2. Read its documentation and try its data
3. Copy the student build prompt
4. Paste the prompt into ChatGPT or Codex
5. Save the returned code as basement-monitor.html
6. Open the file in a browser
7. Refresh the data and verify the result

If you wonder “What do I do next?”

Return to this numbered list. Complete only the next unfinished step.

1. Three ideas you need

You do not need to memorize a long vocabulary list.

IdeaPlain-English meaningToday’s example
API A way for one program to request data or an action from another program. Your dashboard requests live basement readings.
Automation A fixed process that follows rules written in advance. The API compares humidity with a fixed threshold.
Agent An AI system that can work through steps and use approved tools toward a goal. ChatGPT or Codex inspects the API and builds your file.

Simple mental model

API = connection. Automation = fixed steps. Agent = goal plus tools plus decisions within limits.

2. Meet the BaseTemp system

The example is real, but the task is small enough to understand.

What is in the basement?

One Raspberry Pi sensor is near the pellet stove. A second sensor is on the far side of the basement. Both report temperature and humidity.

The Pi running the public API also reports its current CPU temperature.

What can the API tell us?

  • Current readings from both basement sensors
  • A summer humidity result based on a fixed rule
  • The current Raspberry Pi CPU temperature

Do not confuse these levels

LevelQuestion answered
Raw readingWhat is happening now?
Coded ruleDid a known threshold get crossed?
TrendHow has the reading changed over time?
PredictionWhat is likely to happen next?

One current CPU-temperature reading is monitoring, not a prediction. Predicting failure would require historical readings and examples of actual outcomes.

3. Build your dashboard

Complete these steps in order. Do not skip ahead.

Step 1: Open the API page

The BaseTemp page contains the endpoint documentation, live links, a JavaScript example, and the student build prompt.

Open BaseTemp API

Stop and check: you should see the heading BaseTemp API.

Step 2: Inspect the data

On the BaseTemp page, open the three endpoints named in the student prompt. Look at the JSON each one returns.

Stop and check: find both basement sensors, the humidity rule, and the Pi CPU temperature. Return to the BaseTemp page when finished.

Step 3: Copy the student prompt

On the BaseTemp page, find Ask ChatGPT or Codex to build an app. Copy the entire prompt from its first line through the public-publishing approval instruction.

Stop and check: the copied prompt should mention /api/all, /api/humidity-status, and /api/pi.

Step 4: Give the prompt to your AI assistant

Open a new ChatGPT or Codex conversation, paste the prompt, and send it. Allow the assistant to inspect the public API.

If it says an automated request was blocked, let it try through its normal browser. Do not ask it to invent example fields.

Stop and check: the response should contain one complete HTML file in one code block.

Step 5: Save the HTML file

  1. Create a folder named basement-monitor.
  2. Open a plain-text or code editor.
  3. Create a file named basement-monitor.html.
  4. Copy everything inside the HTML code block into the file. Do not copy the three backticks around the code.
  5. Save the file.

Stop and check: the filename must end in .html, not .txt.

Step 6: Open and test the dashboard

  1. Find basement-monitor.html on your computer.
  2. Double-click it to open it in your browser.
  3. Wait for the initial loading message to disappear.
  4. Press the Refresh button.
  5. Confirm that the button indicates loading and then becomes available again.

Stop and check: you should see two sensor readings, the summer humidity status, the Pi CPU temperature, and observation times.

Publishing is optional

If your AI assistant offers to publish the dashboard as a public Site, it must ask first. Publish only if you want the page visible on the internet. The dashboard contains public sensor data, but public sharing is still your decision.

4. If something does not work

Fix the current step; do not start over.

What you seeWhat to do next
The BaseTemp page will not open.Confirm internet access, reload once, and tell the instructor the exact message shown.
The AI assistant cannot inspect the API.Ask it to use its normal browser. If access still fails, report the failure instead of letting it guess fields.
The file opens as text.Confirm its full name is basement-monitor.html and not basement-monitor.html.txt.
The dashboard stays on “Loading.”Open the BaseTemp API page directly. If it works, give the AI assistant the dashboard error and ask it to repair only that problem.
A value says undefined.The code probably guessed a field name. Ask the assistant to compare the code with the actual endpoint JSON.

5. Finished checklist

You are done when every item is true.

  • The dashboard is saved as one HTML file.
  • It displays both basement sensors.
  • It displays the humidity rule and Pi CPU temperature.
  • The Refresh button loads new data.
  • Raw readings are separate from coded-rule results.
  • The page explains why one current reading is not a prediction.
  • You can explain where the data came from.

Key takeaway

An API supplied the data. Fixed code supplied the humidity rule. An AI assistant helped build the interface. You remained responsible for checking the fields, testing the result, and deciding whether to publish.
